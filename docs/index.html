Hoster

This is a placeholder static site for the Hoster project. The original project contains a Node.js backend which cannot run on GitHub Pages.

How to use

  1. The backend runs with Node.js. To start it locally: 
    cd backend
npm install
node backend/server.js
  2. API endpoints are available at http://localhost:3000/api/ by default.
  3. This static page is deployed to GitHub Pages. If you need the full app (backend + Docker), deploy the backend to a server (Railway/Render/Vercel for Node, or a VPS) or run locally.
